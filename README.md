## 🚀 Panduan Deployment ke Vercel

Aplikasi ini telah dioptimalkan 100% untuk deployment instan di **Vercel** (`vercel.json` dan `package.json` sudah terkonfigurasi).

### Opsi 1: Deploy via Vercel CLI (Paling Cepat)

1. Pastikan Anda memiliki Node.js terpasang.
2. Buka terminal di folder ini (`digital_twin`) dan jalankan:
   ```bash
   npx vercel
   ```
3. Ikuti panduan singkat di terminal (tekan `Enter` untuk opsi default). Aplikasi Anda akan langsung online dalam beberapa detik!
4. Untuk deploy ke production domain:
   ```bash
   npx vercel --prod
   ```

### Opsi 2: Deploy via GitHub + Vercel Dashboard

1. Push folder proyek ini ke repository GitHub Anda (misal `github.com/yandri918/digital-twin`).
2. Buka [vercel.com](https://vercel.com) dan login.
3. Klik **"Add New..."** → **"Project"**.
4. Pilih repository GitHub Anda, biarkan pengaturan build standar (*Other / Static Site*).
5. Klik **"Deploy"**.

## 💻 Menjalankan Secara Lokal

Cukup buka file `index.html` langsung di browser Anda, atau jalankan local web server:

```bash
npx serve .
# Atau dengan Python
python -m http.server 8000
```
Lalu buka `http://localhost:8000` (atau port yang tertera).
